What is the heatmap?
Red regions in the Grad-CAM overlay mark areas that most influenced the model's decision. For deepfakes, these typically cluster around eye edges, skin boundaries, and mouth corners — where GAN artifacts are most common.

DeepShield is a cloud-native deepfake detection system built as a Cloud Computing end-semester project at Amrita Vishwa Vidyapeetham, Amritapuri.

The core challenge: it's not enough to say an image is fake. You need to show where. That's why every prediction comes with a Grad-CAM heatmap — a gradient-based visual explanation of exactly which pixels triggered the model.

The backend runs on Google Cloud Run, the model is stored in Cloud Storage, and every prediction is logged to BigQuery for full auditability.
